# 🛒 ZeroPOS - ระบบจัดการร้านค้าและจุดขาย (Point of Sale)

**ZeroPOS** เป็นโปรแกรมแอปพลิเคชันบนระบบปฏิบัติการ Windows (Desktop Application) ที่พัฒนาด้วยภาษา **C# (Windows Forms)** สำหรับใช้เป็นระบบจัดการจุดขาย (POS) ประจำหน้าร้าน โดยรวบรวมฟังก์ชันการทำงานพื้นฐานที่จำเป็นสำหรับร้านค้าไว้อย่างครบถ้วน ตั้งแต่การขายสินค้าหน้าร้าน การจัดการสต็อก การดูแลข้อมูลสมาชิก ไปจนถึงการดูรายงานบิล โดยใช้ระบบฐานข้อมูลแบบ **SQLite** ซึ่งมีขนาดเล็กและไม่ต้องพึ่งพาเซิร์ฟเวอร์แยก

---

## 🚀 ฟีเจอร์หลัก (Key Features)

1. **ระบบขายสินค้าหน้าร้าน (Point of Sale):** หน้าจอคิดเงินที่ใช้งานง่าย รองรับการค้นหาสินค้าและการทำรายการสั่งซื้อ
2. **ระบบจัดการสินค้า (Product & Category Management):** สามารถเพิ่ม ลบ แก้ไข ข้อมูลสินค้าและหมวดหมู่สินค้าได้
3. **ระบบจัดการคลังสินค้า (Stock Management):** ควบคุมและตรวจสอบปริมาณสินค้าคงเหลือ พร้อมดูประวัติการเคลื่อนไหวของสต็อก
4. **ระบบสมาชิก (Member Management):** จัดการข้อมูลลูกค้า/สมาชิก เพื่อนำไปประยุกต์ใช้กับระบบส่วนลดหรือสะสมแต้มในอนาคต
5. **ระบบออกบิลและรายงาน (Bill & Reporting):** บันทึกประวัติการขายและสามารถเรียกดูรายงานหรือค้นหาบิลย้อนหลังได้
6. **ระบบผู้ใช้งาน (Authentication):** มีการควบคุมสิทธิ์และบันทึกเซสชัน (Session) ของพนักงานที่เข้าใช้งานระบบ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Programming Language:** C#
* **UI Framework:** Windows Forms (WinForms)
* **Database:** SQLite (`main_database.db`)
* **IDE/Tools:** Microsoft Visual Studio

## 📂 โครงสร้างโปรแกรมและไฟล์ที่สำคัญ (Project Structure)

โปรแกรมถูกแบ่งการทำงานออกเป็นหน้าต่าง (Forms) และคลาส (Classes) เพื่อให้ง่ายต่อการดูแลรักษา ดังนี้:

### 1. ระบบจัดการฐานข้อมูล (Database & Connection)
* `DatabaseConnection.cs`: คลาสศูนย์กลางที่ทำหน้าที่เชื่อมต่อกับฐานข้อมูล SQLite ทำหน้าที่ประมวลผลคำสั่ง SQL ต่างๆ 
* `main_database.db`: ไฟล์ฐานข้อมูล SQLite ที่เก็บข้อมูลทั้งหมดของระบบ (สินค้า, สมาชิก, บิล, สต็อก ฯลฯ)

### 2. ระบบผู้ใช้งานและหน้าต่างหลัก (Core & Navigation)
* `Program.cs`: จุดเริ่มต้นของโปรแกรม (Entry Point)
* `UserSession.cs`: คลาสสำหรับจัดเก็บและจัดการข้อมูลของพนักงาน/ผู้ใช้ที่กำลังเข้าสู่ระบบ (Log in) อยู่ในปัจจุบัน
* `Form1.cs`: หน้าต่างสำหรับ **เข้าสู่ระบบ (Login)** ตรวจสอบสิทธิ์ผู้ใช้งานก่อนเข้าโปรแกรม
* `Home.cs`: **หน้าหลัก (Dashboard/Menu)** ที่เปรียบเสมือนศูนย์กลางในการกดเข้าไปยังระบบย่อยอื่นๆ ของโปรแกรม
* `SettingsForm.cs`: หน้าต่างสำหรับการตั้งค่าต่างๆ ของโปรแกรม

### 3. ระบบขายสินค้า (Sales & POS)
* `PointOfSale.cs`: **หน้าจอคิดเงินหลัก** สำหรับเลือกสินค้า เพิ่มลงตะกร้า คำนวณยอดรวม และรับชำระเงิน
* `BillReport.cs`: หน้าต่างสำหรับแสดงรายงานการขายและประวัติบิล
* `BillProductSearch.cs` / `BillMemberAdd.cs`: หน้าต่างย่อย (Dialog) สำหรับค้นหาสินค้าเพิ่มเติมและดึงข้อมูลสมาชิกระหว่างการทำรายการขาย
* `BillCoder.cs`: คลาสสำหรับจัดการตรรกะการสร้างเลขที่บิล หรือการเข้ารหัส/จัดรูปแบบบิล

### 4. ระบบจัดการข้อมูล (Management Modules)
* `ProductManagement.cs`: หน้าต่าง **จัดการข้อมูลสินค้า** (กำหนดชื่อ ราคา บาร์โค้ด)
* `CategoryManagement.cs`: หน้าต่าง **จัดการหมวดหมู่สินค้า** เพื่อให้ง่ายต่อการจัดกลุ่มและค้นหา
* `MemberManagement.cs`: หน้าต่าง **จัดการข้อมูลสมาชิก** สำหรับบันทึกข้อมูลลูกค้าของร้าน

### 5. ระบบคลังสินค้า (Inventory)
* `StockManagement.cs`: หน้าต่าง **จัดการสต็อกสินค้า** ใช้สำหรับรับสินค้าเข้า หรือปรับปรุงยอดสินค้าคงเหลือ
* `StockTransactionView.cs`: หน้าต่าง **ดูประวัติความเคลื่อนไหวของสต็อก** (Stock History/Logs) เพื่อตรวจสอบการเข้า-ออกของสินค้า

### 6. ทรัพยากรและรูปภาพ (Resources)
* `src/`: โฟลเดอร์ที่เก็บรูปภาพ ไอคอน (`.png`, `.ico`) และไฟล์พื้นหลังต่างๆ ที่ใช้ประดับตกแต่ง UI ของโปรแกรม (เช่น `box.png`, `cashier.png`, `logo.png` เป็นต้น)
* `Properties/Resources.resx`: ไฟล์จัดการทรัพยากร (Resources) ภายในของ .NET

## ⚙️ ขั้นตอนการทำงานเบื้องต้น (Workflow)

1. ผู้ใช้ (พนักงานแคชเชียร์/ผู้ดูแลระบบ) เปิดโปรแกรมและกรอกรหัสผ่านที่หน้า `Form1.cs`
2. ระบบจะบันทึกข้อมูลผู้ใช้ผ่าน `UserSession.cs` และพาไปที่หน้า `Home.cs`
3. จากหน้า Home ผู้ใช้สามารถเลือกคลิกไอคอนเพื่อไปยังเมนูต่างๆ:
   * กดไปที่ **POS** (`PointOfSale.cs`) เพื่อเริ่มขายสินค้า
   * กดไปที่ **Product / Category** (`ProductManagement.cs` / `CategoryManagement.cs`) เพื่อเพิ่มสินค้าใหม่เข้าระบบ
   * กดไปที่ **Stock** (`StockManagement.cs`) เพื่ออัปเดตจำนวนสินค้าคงคลัง
   * กดไปที่ **Report** (`BillReport.cs`) เพื่อดูยอดขาย
4. ทุกๆ การกระทำ (เช่น การขาย การเพิ่มสต็อก) ระบบจะส่งคำสั่งผ่าน `DatabaseConnection.cs` ไปบันทึกลงไฟล์ `main_database.db` โดยตรง

---

## 📌 วิธีการติดตั้งและรันโปรแกรม (How to Run)

1. Clone หรือดาวน์โหลด Source Code นี้ลงในเครื่อง
2. เปิดไฟล์ `zeropos.slnx` หรือ `zeropos.csproj` ด้วยโปรแกรม **Microsoft Visual Studio**
3. ตรวจสอบให้แน่ใจว่าได้ติดตั้งแพ็กเกจที่จำเป็นสำหรับ SQLite (ถ้ามีระบุใน NuGet)
4. กดปุ่ม `Start` (หรือกด F5) เพื่อคอมไพล์และรันแอปพลิเคชัน
5. ฐานข้อมูลหลักจะถูกดึงมาจากไฟล์ `main_database.db` ที่อยู่ในโปรเจกต์
